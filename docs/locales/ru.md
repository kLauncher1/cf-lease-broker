## ⚡ Ключевые возможности (Highlights)

- **Автономный ротатор токенов на границе (Edge Token Rotator)**: Упреждающий мониторинг жизненного цикла ваучеров аренды и токенов арендаторов с фоновым обновлением при достижении 80% срока действия и поддержкой одновременной валидности обоих токенов в течение 30-секундного льготного периода без простоя (`internal/rotator/rotator.go`).
- **Gossip-сеть отзыва токенов (<5 мс)**: Децентрализованный реестр меток аннулирования (tombstones) со сложностью поиска $O(1)$, подписями HMAC-SHA256, монотонными номерами последовательностей, антиэнтропийной синхронизацией и мгновенным P2P-распространением между узлами кластера (`internal/rotator/mesh.go`).
- **Аппаратная аттестация TPM 2.0 для делегированного обновления**: Криптографическая проверка целостности платформы для делегированных запросов на продление, одноразовые случайные числа (nonces) для защиты от атак повторного воспроизведения и валидация дайджестов PCR (`internal/rotator/attest.go`).
- **Интеллектуальный радар доступности Edge и Anycast-маршрутизация**: Параллельное синтетическое зондирование глобальных точек присутствия (PoP) Cloudflare, отслеживание задержки по экспоненциальному скользящему среднему (EMA, `alpha=0.25`), расчет джиттера и комплексного индекса надежности, субмиллисекундная Anycast-маршрутизация и выявление аномалий BGP (`internal/radar/`).
- **Упреждающая автономная миграция аренды**: Динамический перенос активных аренд микросервисов с деградирующих PoP на работоспособные резервные узлы до возникновения потери пакетов или разрыва соединений.
- **Автономная оптимизация затрат и биллинговый журнал**: Гранулярный учет вычислений, запросов и объема хранилища с микроцентовой точностью ($1.00 = 1 000 000 микроцентов) по официальным тарифам Cloudflare для Workers, KV и R2, а также автоматическое перенаправление трафика на бесплатные учетные записи при угрозе перерасхода (`internal/billing/`).
- **Экспорт в OpenCost 1.0 и другие форматы**: Встроенная выгрузка журналов биллинга в форматах RFC 4180 CSV, JSON с разделителями строк (JSONL) и по стандарту OpenCost 1.0 (`/api/billing/ledger?format=opencost`).
- **Zero-Trust Mutual TLS (mTLS) и аудит клиентских сертификатов**: Комплексная проверка цепочек сертификатов X.509, сверка со списком отзыва (CRL), строгий контроль сроков действия, сопоставление подстановочных SAN (`*.domain.com`) и защита маршрутов обратного прокси (`internal/mtls/verifier.go`).
- **Эфемерный центр сертификации (CA) и пиринговая сеть**: Генерация корневого сертификата ECDSA P-256 в оперативной памяти без внешних зависимостей, динамический выпуск клиентских сертификатов и подписание межкластерных пиринговых токенов (`internal/mtls/ca.go`).
- **Аппаратная аттестация через TPM 2.0 и хранилище сертификатов Windows**: Использование Windows CNG (`ncrypt.dll`) и Microsoft Platform Crypto Provider для подтверждения наличия модуля TPM 2.0 и формирование дайджестов PCR (`internal/mtls/tpm_windows.go`).
- **Высокодоступный консенсус Raft**: Распределенный кластер со случайными таймерами выборов (150-300 мс), кворумом абсолютного большинства, журналом упреждающей записи (WAL) с контрольными суммами SHA-256 и обнаружением узлов через DNS SRV (`internal/raft/`).
- **Виртуальный компилятор и сборщик Edge Worker**: Быстрый лексический минификатор и верификатор в оперативной памяти для пакетов JavaScript/Wasm с удалением комментариев, проверкой синтаксиса и хешированием SHA-256 (`internal/compiler/bundle.go`).
- **Многозонное динамическое внедрение маршрутов**: Высокопроизводительный компилятор шаблонов с подстановочными знаками (`*.domain.com/path/*`), расчетом приоритета и таблицами динамической маршрутизации (`internal/compiler/router.go`).
- **Прямой потоковый конвейер Zero-Copy**: Потоковая передача ответов с ультранизкой задержкой через предварительно выделенные пулы буферов по 64 КБ (`sync.Pool`), мгновенная отправка пакетов (`http.Flusher`) и обнаружение отключения клиента (`internal/compiler/stream.go`).
- **Мультиархитектурные автономные сборки**: Конвейер кросс-компиляции автономных исполняемых файлов для `linux/amd64`, `linux/arm64`, `darwin/arm64` и `windows/amd64` с автоматическим расчетом контрольных сумм SHA-256 (`scripts/build_artifacts.mjs`).
- **Горячая перезагрузка конфигурации без простоя**: Синхронизация учетных записей и пулов на лету посредством отслеживания изменений файлов и системных сигналов (`SIGHUP`) без перезапуска службы.
- **Агрегация квот между учетными записями**: Объединение нескольких бесплатных и платных аккаунтов Cloudflare в виртуальный вычислительный кластер для преодоления суточных лимитов.
- **Промышленное хранилище секретов**: Шифрование конвертов данных через Windows DPAPI (`CryptProtectData`) и кросс-платформенный AES-256-GCM с гарантированной очисткой памяти (`Zeroize`).
- **Аутентификация HS256 JWT и модель RBAC**: Движок токенов HMAC-SHA256 с валидацией за постоянное время и потокобезопасным черным списком отозванных JTI.
- **Виртуальный шлюз R2, совместимый с S3**: Интерфейс S3 REST (`/s3/{bucket}/{key...}`) с автоматической фрагментацией объектов по 2 МБ и составной проверкой целостности ETag.
- **Секционированный кэш KV для пула аккаунтов**: Потокобезопасный слой хранения KV с консистентным хешированием FNV, LRU-кэшем в памяти и контролем времени жизни TTL.
- **Экспортер метрик Prometheus 0.0.4**: Стандартный эндпоинт `/metrics` для сбора данных по выданным арендам, лимитам аккаунтов и сетевой телеметрии.
- **Ограничение частоты запросов методом скользящего окна**: Отслеживание трафика в оперативной памяти с автоматическим переводом на испытательный срок с экспоненциальной задержкой.
- **Мультиканальные вебхуки уведомлений**: Информативные оповещения для Discord, Slack и в формате JSON при исчерпании 80%, 95% и 100% квоты.
- **Перехват ошибок 429 и мгновенное переключение**: Отслеживание статусов HTTP 429 Too Many Requests и сбоев шлюза с автоматической передачей запроса следующему доступному аккаунту.
- **Прозрачный обратный прокси**: Маршрутизация трафика через `/proxy/{service}/*` с буферизацией тела запроса и удалением служебных заголовков по стандарту RFC 7230.
- **Динамическая аренда ресурсов (Ваучеры)**: Выпуск краткосрочных изолированных токенов API (`lse_...`) для микросервисов и автоматизированных тестов.
- **Развертывание в виде единого бинарного файла**: Панель управления с современным дизайном Glassmorphism встроена прямо в исполняемый файл Go с помощью `//go:embed`.
- **Минимальное потребление памяти**: Стабильная работа при расходе менее **12 МБ ОЗУ** без внешних зависимостей.

## 🚀 Быстрый старт (Quick Start)

### 1. Загрузка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/kLauncher1/cf-lease-broker.git
cd cf-lease-broker

# Непосредственный запуск
go run .
```

Панель управления будет доступна по адресу:
👉 **`http://localhost:9081`**

```bash
# Сборка исполняемых файлов для linux/amd64, linux/arm64, darwin/arm64 и windows/amd64
node scripts/build_artifacts.mjs --clean

# Проверка криптографических контрольных сумм SHA-256
node scripts/build_artifacts.mjs --verify
```

## 🔒 Управление секретами и авторизация

### 1. Хранилище с конвертным шифрованием (`internal/security/vault.go`)
- **Интеграция с Windows DPAPI**: В среде Windows секреты защищаются средствами операционной системы через `CryptProtectData` (`dpapi:<base64>`).
- **Конверт AES-256-GCM**: В других средах применяется аутентифицированное шифрование AES-256-GCM с уникальными 96-битными одноразовыми числами.
- **Зачистка оперативной памяти**: Буферы с конфиденциальными данными немедленно обнуляются после завершения операции по шаблону `Zeroize`.

### 2. Middleware JWT и RBAC (`internal/security/middleware.go`)
- **Стандартные токены HS256**: Выпуск и проверка подписей HMAC-SHA256 за постоянное время для предотвращения атак по времени исполнения.
- **Черный список отзыва**: Поддержка мгновенной аннуляции токенов по идентификатору JTI (`POST /api/auth/revoke`).
- **Защита интерфейсов администрирования**: Доступ к ключевым эндпоинтам требует передачи заголовка `Authorization: Bearer <token>`.

```bash
# 1. Выпуск токена JWT для оператора
curl -X POST http://localhost:9081/api/auth/token \
  -H "Content-Type: application/json" \
  -d '{"sub": "gateway-client", "role": "operator", "duration_hours": 24}'

# 2. Вызов защищенного интерфейса аренды
curl -X GET http://localhost:9081/api/leases \
  -H "Authorization: Bearer <issued_jwt_token>"
```

## 🪣 Виртуальный шлюз R2, совместимый с S3 (`/s3/{bucket}/{key...}`)

Брокер предоставляет стандартные эндпоинты, совместимые с протоколом AWS S3:
1. **Чередующаяся фрагментация**: Загружаемые объекты объемом более 2 МБ разбиваются на последовательные блоки (`chk_<hash>_<index>`) и распределяются по пулу учетных записей.
2. **Контрольные суммы целостности**: Каждый блок получает отдельный хеш SHA-256, формируя составной ETag для объекта.
3. **Запросы диапазонов байт (HTTP Range)**: Поддержка заголовка `Range: bytes=start-end` для потокового видео и докачки файлов.
4. **Список объектов**: Формирование стандартного XML-ответа `ListBucketResult` по спецификации `ListObjectsV2`.

```bash
# 1. Загрузка объекта в пул хранилища R2
curl -i -X PUT http://localhost:9081/s3/assets/docs/whitepaper.pdf \
  -H "Content-Type: application/pdf" \
  --data-binary "@whitepaper.pdf"

# 2. Скачивание сохраненного объекта
curl http://localhost:9081/s3/assets/docs/whitepaper.pdf -o downloaded.pdf

# 3. Запрос диапазона байт
curl -i -H "Range: bytes=0-1048575" http://localhost:9081/s3/assets/docs/whitepaper.pdf
```

## 🔄 Прозрачный обратный прокси с аварийным переключением (`/proxy/{service}/*`)

1. **Маршрутизация к оптимальному аккаунту**: Запрос направляется к учетной записи с наибольшим остатком суточной квоты (`SelectOptimalAccount`).
2. **Буферизация тела запроса**: Сохранение в оперативной памяти запросов размером до 10 МБ для безопасных повторных попыток без потери данных.
3. **Перехват кодов 429**: При получении ошибки 429 или сбоев 502/503/504 учетная запись переводится в нерабочее состояние, а запрос немедленно повторяется через другой аккаунт.
4. **Удаление служебных заголовков**: Исключение заголовков Hop-by-Hop по стандарту RFC 7230 в обоих направлениях.
5. **Диагностические заголовки**: Включение в ответ заголовков `X-CF-Broker-Account` и `X-CF-Broker-Attempts`.

3. **Потоковая передача Zero-Copy**: Передача данных через пулы буферов по 64 КБ с поддержкой `http.Flusher` без нагрузки на сборщик мусора.

## 🤝 Отказоустойчивый консенсус Raft

1. **Выборы лидера большинством**: Случайные таймеры от 150 до 300 мс и рассылка сигналов heartbeat каждые 50 мс.
2. **Журнал упреждающей записи (WAL)**: Строгая последовательная индексация с проверкой контрольных сумм SHA-256.
3. **Обнаружение узлов через DNS SRV**: Динамическое подключение участников кластера по записям RFC 2782 (`net.LookupSRV`).
4. **Конечный автомат брокера**: Репликация команд `GRANT_LEASE`, `REVOKE_LEASE`, `SYNC_ACCOUNT` и `UPDATE_QUOTA`.
