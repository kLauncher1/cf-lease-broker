## ⚡ أبرز الميزات (Highlights)

- **مُدوِّر رموز الحافة الذاتي (Autonomous Edge Token Rotator)**: مراقبة استباقية لدورة حياة قسائم الإيجار ورموز المستأجرين مع تجديد تلقائي في الخلفية عند بلوغ 80% من فترة الصلاحية، وصلاحية مزدوجة للرموز دون توقف خلال فترة سماح مدتها 30 ثانية (`internal/rotator/rotator.go`).
- **شبكة إلغاء الرموز القائمة على Gossip (<5ms)**: دفتر أستاذ لامركزي لشواهد الإلغاء (Tombstones) مع بحث $O(1)$، وتوقيع HMAC-SHA256، وترقيم تسلسلي تصاعدي، ومزامنة ضد الإنتروبيا وبث فوري بين العقد في أقل من 5 مللي ثانية (`internal/rotator/mesh.go`).
- **إثبات صحة منصة الأجهزة عبر TPM 2.0 للتحديث المفوض**: التحقق المشفر من سلامة المنصة لطلبات التجديد المفوضة، مع أرقام عشوائية لمرة واحدة (Nonces) لمنع هجمات إعادة التشغيل، والتحقق من سجلات تكوين المنصة (PCR) في وقت ثابت (`internal/rotator/attest.go`).
- **رادار صحة الحافة الذكي وتوجيه Anycast الجغرافي**: فحص اصطناعي متزامن لنقاط تواجد Cloudflare عالمياً (PoPs)، وتتبع متوسط زمن الانتقال المتنقل (EMA، `alpha=0.25`)، والارتعاش (Jitter)، مع توجيه Anycast دون المللي ثانية واكتشاف تقلب مسارات BGP (`internal/radar/`).
- **ترحيل الإيجار الاستباقي التلقائي (Pre-Emptive Lease Migration)**: نقل إيجارات الخدمات المصغرة النشطة تلقائياً بعيداً عن نقاط PoPs المتدهورة إلى بدائل احتياطية قبل حدوث فقدان للحزم أو انقطاع في الاتصال.
- **التحسين الذاتي للتكلفة ودفتر فواتير المستأجرين**: قياس دقيق للحوسبة والطلبات والتخزين بحساب أجزاء السنت ($1.00 = 1,000,000 ميكروسنت) وفقاً لأسعار Cloudflare الرسمية، مع إعادة توجيه أعباء العمل تلقائياً إلى الحسابات المجانية الاحتياطية عند اقتراب تجاوز الحدود المدفوعة (`internal/billing/`).
- **تصدير مالي قياسي OpenCost 1.0 وتنسيقات متعددة**: دعم فوري لتصدير دفاتر الفواتير بتنسيق RFC 4180 CSV، وتنسيق JSON مفصول بأسطر (JSONL)، ومواصفات OpenCost 1.0 القياسية (`/api/billing/ledger?format=opencost`).
- **أمان ثنائي الأطراف mTLS مع التحقق من شهادات العميل**: تدقيق شامل لسلاسل شهادات X.509، وقوائم إبطال الشهادات (CRL)، ونطاقات الصلاحية، ومطابقة الأسماء البديلة (SAN) بالرموز البديلة (`*.domain.com`)، وحماية مسارات الوكيل العكسي (`internal/mtls/verifier.go`).
- **سلطة شهادات مؤقتة (Ephemeral CA) وشبكة اقتران**: توليد شهادة جذر ECDSA P-256 في الذاكرة دون أي تبعيات خارجية، وإصدار شهادات عملاء ديناميكية، ورموز اقتران مشفرة بين العناقيد (`internal/mtls/ca.go`).
- **إثبات العتاد عبر TPM 2.0 ومخزن شهادات Windows**: استخدام واجهة Windows CNG (`ncrypt.dll`) للوصول إلى Microsoft Platform Crypto Provider ومخزن شهادات النظام (`crypt32.dll`) لتوليد قياسات PCR موثوقة (`internal/mtls/tpm_windows.go`).
- **محرك إجماع Raft عالي التوفر**: عنقود Raft موزع بمؤقتات انتخاب عشوائية (150-300ms)، وانتخاب قائد بالأغلبية المطلقة، وسجل معاملات مسبق الكتابة (WAL) مع تدقيق بصمة SHA-256، واكتشاف ديناميكي للنظراء عبر DNS SRV (`internal/raft/`).
- **مترجم وحزم Worker الافتراضي**: أداة تصغير والتحقق المعجمي السريع في الذاكرة لحزم JavaScript/Wasm مع إزالة التعليقات، والتحقق النحوي، وحساب تجزئة SHA-256 للمحتوى (`internal/compiler/bundle.go`).
- **حقن المسارات الديناميكية متعددة المناطق**: مترجم مسارات عالي الأداء يدعم النطاقات البديلة (`*.domain.com/path/*`) مع أوزان الأولوية وحقن المسارات ديناميكياً (`internal/compiler/router.go`).
- **تدفق مباشر دون نسخ للبيانات (Zero-Copy)**: تدفق فائق السرعة للاستجابات عبر أحواض مخازن مؤقتة مخصصة بحجم 64 كيلوبايت (`sync.Pool`)، وإفراغ فوري للحزم (`http.Flusher`)، واكتشاف انقطاع العميل لمنع تسريب المقابس (`internal/compiler/stream.go`).
- **حزم تنفيذية مستقلة متعددة المعماريات**: خط تجميع وإنتاج حزم مستقلة جاهزة للعمل على `linux/amd64` و `linux/arm64` و `darwin/arm64` و `windows/amd64` مع إنشاء تلقائي لمطابقات SHA-256 (`scripts/build_artifacts.mjs`).
- **إعادة تحميل ساخنة دون انقطاع الخدمة**: تحديث مستمر لبيانات الاعتماد والحسابات بمراقبة تعديلات الملفات وإشارات النظام (`SIGHUP`) دون إعادة تشغيل العملية.
- **تجميع حصص الحسابات المتعددة**: دمج حسابات Cloudflare المتعددة في عنقود حوسبي افتراضي واحد لتجاوز حدود الاستخدام اليومي الفردي.
- **خزينة أسرار احترافية**: تشفير محكم للبيانات باستخدام Windows DPAPI (`CryptProtectData`) وتشفير AES-256-GCM متوافق عبر الأنظمة مع تنظيف فوري للذاكرة (`Zeroize`).
- **مصادقة HS256 JWT والتحكم بالوصول المبني على الأدوار (RBAC)**: محرك رموز HMAC-SHA256 مع فحص توقيع بزمن ثابت وقوائم منع رموز JTI الملغاة.
- **بوابة R2 افتراضية متوافقة مع S3**: واجهات بروتوكول S3 REST (`/s3/{bucket}/{key...}`) مع تقسيم تلقائي بحجم 2 ميجابايت ومطابقة تكامل مركبة ETag.
- **ذاكرة تخزين مؤقت KV مقسمة متعددة الحسابات**: طبقة تخزين آمنة للخيوط مع تجزئة متسقة FNV وذاكرة مؤقتة LRU مع سياسة انتهاء صلاحية TTL.
- **مصدّر مقاييس Prometheus 0.0.4**: نقطة استقصاء قياسية `/metrics` لتصدير إحصائيات الإيجارات والحصص وتليمترية الوكيل دون تبعيات.
- **تحديد معدل الطلبات عبر النافذة المنزلقة مع فترة مراقبة**: تتبع الطلبات مع فترة مراقبة وتراجع أسي للحسابات الخاضعة لتقييد المعدل.
- **تنبيهات الويب المتعددة (Webhooks)**: إشعارات غنية لـ Discord و Slack و JSON عند عتبات 80% و 95% و 100%.
- **اعتراض أخطاء 429 والتحويل التلقائي عند الأعطال**: اعتراض فوري لأخطاء معدل الطلبات HTTP 429 مع إعادة توجيه تلقائية للحساب التالي السليم في الحوض.
- **وكيل عكسي شفاف**: إعادة توجيه سريعة عبر `/proxy/{service}/*` مع إعادة محاولة للبيانات وحذف ترويسات القفزات وفق RFC 7230.
- **تأجير ديناميكي للموارد**: إصدار رموز مؤقتة ومحددة الصلاحيات (`lse_...`) للخدمات المصغرة أو أدوات الاختبار.
- **توزيع في ملف تنفيذي واحد**: لوحة تحكم عصرية بنمط Glassmorphism مدمجة مباشرة في ملف Go الثنائي عبر `//go:embed`.
- **استهلاك ضئيل للذاكرة**: يعمل باستمرار بأقل من **12 ميجابايت من الذاكرة العشوائية (RAM)** دون أي متطلبات تشغيل خارجية.

## 🔒 إدارة الأسرار والمصادقة

### 1. خزينة التشفير المحكم (`internal/security/vault.go`)
- **تكامل Windows DPAPI**: على أنظمة Windows، تتم حماية البيانات عبر واجهة DPAPI (`CryptProtectData`) باستخدام صلاحيات نظام التشغيل (`dpapi:<base64>`).
- **تشفير AES-256-GCM**: على الأنظمة الأخرى، يتم تشفير البيانات باستخدام خوارزمية AES-256-GCM مع أرقام عشوائية 96-بت فريدة.
- **تفريغ الذاكرة الآمن**: إفراغ المخازن المؤقتة الحساسة مباشرة بعد الاستخدام باستخدام نمط `Zeroize`.

### 2. برمجية JWT و RBAC الوسيطة (`internal/security/middleware.go`)
- **رموز HS256 القياسية**: إصدار والتحقق من رموز HMAC-SHA256 في وقت ثابت لمنع هجمات التوقيت الجانبية.
- **قوائم الإلغاء الفورية**: دعم إلغاء الرموز فوراً بواسطة معرف JTI (`POST /api/auth/revoke`).
- **حماية واجهات الإدارة**: تتطلب جميع الواجهات الحساسة ترويسة تفويض صالحة `Authorization: Bearer <token>`.

```bash
# 1. إصدار رمز JWT للمشغل
curl -X POST http://localhost:9081/api/auth/token \
  -H "Content-Type: application/json" \
  -d '{"sub": "gateway-client", "role": "operator", "duration_hours": 24}'

# 2. استدعاء واجهة الإيجارات المحمية
curl -X GET http://localhost:9081/api/leases \
  -H "Authorization: Bearer <issued_jwt_token>"
```

## 🪣 بوابة R2 الافتراضية المتوافقة مع S3 (`/s3/{bucket}/{key...}`)

توفر البوابة نقاط وصول قياسية متوافقة مع بروتوكول AWS S3:
1. **التقسيم التلقائي**: تقسيم البيانات التي تتجاوز 2 ميجابايت إلى كتل متسلسلة (`chk_<hash>_<index>`) وتوزيعها عبر حسابات الحوض.
2. **فحص التكامل**: تشتمل كل كتلة على بصمة تجزئة SHA-256 فردية، ويحصل الكائن على علامة ETag مركبة.
3. **طلبات النطاق الجزئي (HTTP Range)**: دعم ترويسة `Range: bytes=start-end` لبث الفيديو واستئناف التحميل.
4. **سرد الكائنات**: التوافق مع استجابات XML القياسية لـ `ListObjectsV2`.

```bash
# 1. تخزين كائن عبر حوض R2
curl -i -X PUT http://localhost:9081/s3/assets/docs/whitepaper.pdf \
  -H "Content-Type: application/pdf" \
  --data-binary "@whitepaper.pdf"

# 2. استرجاع الكائن
curl http://localhost:9081/s3/assets/docs/whitepaper.pdf -o downloaded.pdf

# 3. طلب نطاق جزئي للبيانات
curl -i -H "Range: bytes=0-1048575" http://localhost:9081/s3/assets/docs/whitepaper.pdf
```

## 🔄 وكيل عكسي شفاف مع تحويل عند الأعطال (`/proxy/{service}/*`)

1. **تحديد الهدف**: توجيه الطلب إلى الحساب صاحب أعلى رصيد متبقٍ من الحصة في الحوض (`SelectOptimalAccount`).
2. **تخزين مؤقت للبيانات**: حفظ حمولة الطلب في الذاكرة (حتى 10 ميجابايت) لإعادة المحاولة بأمان دون فقدان البيانات.
3. **اعتراض أخطاء 429**: عند تلقي HTTP 429 أو أخطاء البوابة 502/503/504، يتم تمييز الحساب كغير سليم والمحاولة فوراً مع الحساب التالي.
4. **تنظيف الترويسات**: إزالة ترويسات القفزات وفق معيار RFC 7230 في كلا الاتجاهين.
5. **ترويسات التليمترية**: تتضمن الاستجابة ترويسات `X-CF-Broker-Account` و `X-CF-Broker-Attempts`.

## 🔄 إعادة التحميل الساخنة دون توقف الخدمة (`internal/config/`)

1. **حلقة مراقبة الملفات**: مراقبة دورية لملف الإعدادات وتدقيق التغييرات عبر بصمات SHA-256 لمنع التحميل العشوائي.
2. **التعامل مع إشارات POSIX**: التقاط إشارة `SIGHUP` لتنفيذ إعادة تحميل فورية ومتزامنة للإعدادات.
3. **أمان التبديل الذري**: في حال وجود أخطاء في ملف التكوين، يفشل التحديث بأمان مع الحفاظ على التكوين النشط دون أي تأثير.

## 🚀 مترجم وحزم Worker الافتراضي وحقن المسارات

1. **تصغير وتحليل معجمي في الذاكرة**: تنظيف التعليقات والتحقق من توافق توقيع تصدير وحدات Cloudflare Worker.
2. **مترجم المسارات متعدد المناطق**: ربط المسارات البديلة (`*.domain.com/*`) وتقييم أولوياتها بحسب درجة التخصيص.
3. **تدفق مباشر دون نسخ للبيانات**: استخدام مصفوفات بحجم 64 كيلوبايت مع `http.Flusher` لنقل البيانات بأعلى سرعة وأقل تأخير.

## 🤝 محرك إجماع Raft الموزع عالي التوفر

1. **انتخاب القائد بالأغلبية**: مؤقتات انتخاب عشوائية بين 150-300 مللي ثانية ونبضات قلب كل 50 مللي ثانية.
2. **سجل المعاملات المسبق (WAL)**: فهرسة تصاعدية وتدقيق متواصل لسلامة السجلات ببصمة SHA-256.
3. **اكتشاف النظراء عبر DNS SRV**: اكتشاف العقد تلقائياً عبر سجلات RFC 2782 (`net.LookupSRV`).
4. **آلة الحالة الموزعة (Broker FSM)**: مزامنة أوامر `GRANT_LEASE` و `REVOKE_LEASE` و `SYNC_ACCOUNT` و `UPDATE_QUOTA`.

3. **إثبات المنصة عبر TPM 2.0**: استعلام واجهات Windows CNG `ncrypt.dll` لتوثيق قياسات PCR وسجلات المنصة.

## 🛰️ رادار صحة الحافة وتوجيه Anycast الجغرافي

1. **فحص اصطناعي لنقاط الحافة**: تتبع زمن الانتقال بمتوسط متحرك (EMA) وقياس الارتعاش وفقدان الحزم.
2. **توجيه جغرافي Anycast فائق الدقة**: حساب مسافات Haversine لتحديد أقرب نقطة تواجد مع الحفاظ على ارتباط المستأجر.
3. **اكتشاف تقلب مسارات BGP**: نقل استباقي للإيجارات النشطة بعيداً عن النقاط المتأثرة قبل انقطاع الخدمة.

---

## 🔄 مُدوِّر الرموز الذاتي وشبكة إلغاء Gossip

1. **تجديد استباقي للرموز**: فحص مستمر وتجديد تلقائي عند 80% من فترة الصلاحية مع فترة سماح 30 ثانية.
2. **شبكة إلغاء Gossip (<5ms)**: نشر فوري لشواهد الإلغاء الموقعة عبر العقد في أقل من 5 مللي ثانية.
3. **تفويض التجديد الموثق بالعتاد**: حماية طلبات التجديد المفوضة بأرقام عشوائية لمرة واحدة وقياسات TPM 2.0.
